# Dissolve

This feature allows you to dissolve (merge) geographic entities into larger ones.

This operation is useful for merging geographical data on a larger scale than that of the initial data.

You can :

- choose a grouping field (for example, the name of a department) ;
- choose to dissolve all entities in the layer.
